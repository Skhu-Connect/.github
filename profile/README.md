# 성공잇다

학교에 하고 싶은 말이 있어도 어디에 말해야 할지 몰라 그냥 넘긴 적, 다들 한 번쯤 있습니다.

**성공잇다**는 학교 이메일로 재학생 인증을 마친 학생이 **익명으로** 건의를 올리고,
다른 학생들이 **요청**으로 힘을 보태는 서비스입니다.
요청이 학과 정원 또는 전체 학생 수 기준 **도달률 100%** 에 닿으면 건의는 **담당 부서로 자동 전달**되고,
검토를 거쳐 **공식 답변**이 등록됩니다. 접수부터 답변까지의 처리 상태는 앱에서 그대로 보입니다.

## 이렇게 동작합니다

1. **재학생 인증** — 성공회대 이메일로 가입합니다.
2. **익명 건의** — 장학·시설·기숙사·도서관·학부 등 카테고리를 고르고 글을 남깁니다. 작성자는 끝까지 익명입니다.
3. **요청으로 공감** — 카테고리마다 정해진 도달 기준이 있고, 학생들의 요청이 그 기준을 채웁니다.
4. **자동 전달·공식 답변** — 기준을 넘긴 건의는 담당 부서로 전달되고, 검토 후 공식 답변이 달립니다.


## 주요 기능

#### 건의 · 탐색
- 장학 · 시설 · 기숙사 · 도서관 · 학부 등 카테고리별 **익명 건의 등록**
- 검색, 카테고리 필터, 요청순 · 최신순 정렬
- **급상승 건의**와 기간별 활동 요약으로 지금 뜨는 의견 확인

#### 공감 · 참여
- **요청(공감) 등록·취소** — 서버가 1인 1회를 보장해 중복 참여를 막습니다
- 카테고리마다 학과 정원 또는 전체 학생 수 기준의 **도달 기준**이 걸리고, 100% 달성 시 자동으로 검토 상태로 넘어갑니다
- **익명 댓글·대댓글**과 댓글 공감 — 건의마다 영구 익명 번호가 붙어 같은 사람의 발언을 이어서 읽을 수 있습니다
- **북마크**와 **공유 링크 복사** — 링크를 받은 학생은 로그인 후 바로 그 건의에 요청할 수 있습니다

#### 처리 · 답변
- **접수 → 검토중 → 답변 완료** 단계별 처리 상태를 그대로 공개
- 담당 부서가 등록한 **공식 답변**을 앱에서 바로 확인

#### 알림
- 공감 목표 달성 · 검토 시작 · 공식 답변 등록 · 댓글과 답글 · 새 공지사항
- **종류별로 켜고 끄기** — 받고 싶은 알림만 받습니다

#### 내 활동
- 내가 등록한 건의, 누른 요청, 받은 답변, 북마크한 건의, 작성한 댓글을 MY 화면에서 모아보기

#### 안전 · 계정
- 부적절한 게시글·댓글 **신고**, 원하지 않는 **사용자 차단** — 차단하면 그 사용자의 글과 댓글이 더 이상 보이지 않습니다
- 학교 이메일 인증 가입, 아이디 찾기 · 비밀번호 재설정
- 아이디 · 비밀번호 · 소속 학부 변경, 회원탈퇴

#### 관리자 콘솔
- 카테고리별 도달 기준(임계치) 조회·수정
- 청원·댓글 숨김·복구, **공식 답변 등록·수정**, 운영 로그 조회
